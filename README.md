# SPARTAN GYM

Sistema de gestión para gimnasio desarrollado con Node.js (backend) y HTML/CSS/JS (frontend).

## Estructura

- `backend/` — API REST con Express, PostgreSQL y Firebase
- `frontend/` — Interfaz web estática

## Requisitos

- Node.js 18+
- PostgreSQL

## Instalación

```bash
npm install
cd backend && npm install
```
